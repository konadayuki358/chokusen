直線距離ログ。 v1.0
=================

【公開方法】
1. ZIPを解凍してください。
2. index.html、app.js、styles.css、sw.js、manifest.webmanifest、iconsフォルダをGitHubリポジトリのルートにアップロードしてください。
   ※ZIP自体をアップロードしてもWebアプリにはなりません。
3. GitHubリポジトリの Settings → Pages で、Deploy from a branch、main、/(root) を選んで保存します。
4. 公開されたHTTPSのURLをAndroidのChromeで開き、位置情報を許可してください。
5. Chromeのメニューに「アプリをインストール」または「ホーム画面に追加」が表示されたら操作します。
   ※表現やインストール可能判定はChromeのバージョン・端末により異なります。

【動作概要】
・「開始地点を記録」で緯度経度と日時を端末内に一時保存します。端末の電源を切っても継続できます。
・「終了地点を記録」で距離を端末内で計算します。10m以下は記録しません。
・画面の累計距離や履歴の距離をタップすると、全ての距離表示が m と km で切り替わります。データは常に m 単位で保存されます。
・10mを超えたときのみ累計距離に加算し、履歴を最新10件に更新します。開始座標は終了計測時に削除します。
・終点の取得に失敗した場合は、開始座標を保存したまま再取得できます。
・右上の歯車から引き継ぎコードを発行・復元できます。座標は引き継がれません。
・初回オンライン起動でService Workerのインストールが完了すると、次回以降はオフラインでもアプリの画面を表示できます。

【既存のGitHub Pagesを更新する場合】
・旧ファイルを削除する必要はありません。ZIPを解凍し、同名ファイルとiconsフォルダをリポジトリのルートへアップロードして上書きしてください。
・画面上のバージョン表記は v1.0 のままです。オフラインキャッシュだけ更新しています。
・公開後に旧画面が出る場合は、ページを再読み込みし、必要なら少し待って再読み込みしてください。アプリデータ保護のためサイトデータの削除は避けてください。

【実機テスト手順】
1. 公開ページをChromeで表示し、開始地点を記録する。
2. Chromeを閉じる・スマホを再起動するなどした後も「開始地点を記録済みです」となるか確認する。
3. 10mを十分超える距離へ移動して終了を押す。履歴と累計が更新されるか確認する。
4. 10m以下の移動で終了を押し、記録が増えないことを確認する（位置情報誤差で10m超になる場合があります）。
5. 歯車 → 引き継ぎコードを発行し、コピーして保存。別ブラウザ/端末への復元を試す。
6. いちどオンラインでアプリを開いた後、機内モードなどでオフライン起動を確認する。
7. Chromeのメニューからホーム画面への追加/アプリのインストールを試す。

【注意点】
・ブラウザのサイトデータを削除すると、記録や計測中の開始地点が失われる場合があります。
・位置情報サービスの精度や通信は、端末・OS・ブラウザの設定と周辺環境によって変わります。
・引き継ぎコードは暗号化していません。コードには日時と距離が含まれます。
・GPS等の座標をアプリ独自の通信で送信する機能や、外部のJavaScript/CSSライブラリはありません。
・ファイルを直接ダブルクリックして file:// から起動する方法ではPWAや位置情報機能の実機検証はできません。HTTPSの公開URLから確認してください。
・本アプリでは一度保存した累計距離・履歴を個別に削除する画面は設けていません。コードの復元による上書きと、ブラウザ側のサイトデータ削除は可能です。
